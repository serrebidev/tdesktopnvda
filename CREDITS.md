# Credits

Telegram Desktop Accessibility is an NVDA add-on for Telegram Desktop on Windows, based on [keyang556/tdesktopnvda](https://github.com/keyang556/tdesktopnvda) by Ken Chang (lindsay714322@gmail.com). It adds direct navigation commands (focus the selected chat, jump to the menu, switch chats and hear the new chat's title) and announces the active chat while switching conversations. Telegram's native accessibility behavior and accessible names are unchanged.

Telegram Desktop is Telegram's. NVDA is NV Access's. Ken Chang's add-on is the original; this repository extends it. This add-on only adds the commands and labels between them.

Questions and bug reports are welcome in the [SerrebiProjects Telegram group](https://t.me/SerrebiProjects). More serrebi projects: [projects.serrebiradio.com](https://projects.serrebiradio.com).
